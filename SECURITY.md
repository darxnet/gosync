# Security Policy

## Supported versions

Only the latest release receives security fixes. Upgrade to the latest
`github.com/darxnet/gosync` before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub:
<https://github.com/darxnet/gosync/security/advisories/new>

You will get an acknowledgement within 72 hours and a fix, or a mitigation
plan, within 14 days. Reporters are credited in the release notes unless
they ask otherwise.
